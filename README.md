One image summing up the world's news of Monday 23 November 2026, drawn in code: COP31 collapses in Antalya, Nvidia soars as Jensen Huang returns, Russian missiles land in Poland, and Ukraine sinks a Russian warship off Libya — plus four more briefs.

## Run it

```sh
node main.ts
```

`main.ts` draws the 1024x1024 front page with Node's standard library only (its own PNG encoder, pixel drawing and a 5x7 bitmap font) and writes `entry.png` to `/output` (or `$MAKEFUN_OUTPUT_DIR`). No network, no bundled image: the same bytes on every run.
